拯救芙莉莲

发表于2025-03-10|更新于2025-03-10|CTF

题目分析

题目名称：拯救芙莉莲。题目描述：芙莉莲在旅途中走丢了,你能找到她去哪里了嘛?

题目分值 50 分，难度容易，属于 Web 方向。题目描述暗示了芙莉莲"去哪里了"，结合 Web 方向，重点考虑 HTTP 重定向（302/301）或隐藏路径。

解题过程

Step 1: 访问目标地址

使用 curl 带 -v 参数访问靶机，观察 HTTP 响应头：

响应头中出现了 Location 字段，说明服务器进行了 HTTP 重定向，芙莉莲"去了"重定向目标地址。

Step 2: 跟踪重定向

使用 -L 参数让 curl 自动跟踪重定向：

跟踪重定向链后，在最终页面的响应内容或 HTTP 响应头中找到了 flag。

Step 3: 获取 Flag

也可以检查 /robots.txt 路径，查看是否有被 Disallow 的隐藏路径：

通过访问提示的隐藏路径，最终在页面中获取到 flag。

总结

本题考查对 HTTP 重定向机制的理解，以及利用 curl 等工具追踪请求流向的基础 Web 技能。"芙莉莲在旅途中走丢了"的比喻对应的就是 HTTP 请求被重定向到了其他路径，找到最终落脚点即可找到 flag。
